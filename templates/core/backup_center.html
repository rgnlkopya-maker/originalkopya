Otomatik yedekleme nasıl çalışır?

Her modül için seçtiğiniz sıklık ve saat ayrı ayrı kaydedilir. Sistem Türkiye saatine göre yedeklemeyi başlatır ve sonucu aşağıdaki geçmişe işler. Manuel yedeklemeyi de istediğiniz zaman kullanabilirsiniz.

{% for item in policies %}

{{ item.name }}

Zamanlamayı düzenleyin; ayrıntılar için kuralları açın.
Yedekleme kurallarını görüntüle
{% if item.key == 'folios' %}

1. Föyler kontrol edilir. Sistem kayıtlı sipariş föylerini sırayla inceler ve mevcut Drive yedekleriyle karşılaştırır.

2. Föy belgeleri hazırlanır. Her föyün yazdırma görünümü PDF ve HTML olarak, kayıt bilgileri ise JSON olarak hazırlanır.

3. Dosyalar ayrı klasörlere aktarılır. PDF'ler “MoliApp Föyleri”, HTML kopyaları “Yazdırma HTML Kopyaları”, JSON dosyaları “Veri Yedekleri”, kaynak görseller “Orijinal Föyler” klasörlerinde saklanır.

4. Gereksiz tekrarlar önlenir. Değişmeyen belgeler ve daha önce yüklenmiş orijinal fotoğraflar yeniden yüklenmez; yeni veya değişen dosyalar eklenir.

5. Sonuç kaydedilir. İşlenen föy ve yeni dosya sayıları Yedekleme Geçmişi'nde gösterilir; hata olursa kayıt tutulur.

{% else %}

1. Güncel kayıtlar okunur. Sistemdeki çek ve senetlerin tamamı alınır.

2. Excel ve JSON hazırlanır. Okunabilir çek/senet listesi Excel olarak, kayıtların veri kopyası JSON olarak oluşturulur. Her yedekleme işleminde bu iki dosyanın yeni tarihli kopyası saklanır.

3. Fotoğraflar kontrol edilir. Çek/senet görselleri Drive'daki dosyalarla karşılaştırılır. Yalnızca eksik fotoğraflar yüklenir.

4. Mevcut yedekler korunur. Eski Excel, JSON ve fotoğraflar silinmez; yeni yedekler ilgili klasörlere eklenir.

5. Sonuç kaydedilir. İşlenen kayıt sayısı, yeni fotoğraf sayısı ve işlem sonucu Yedekleme Geçmişi'ne yazılır.

{% endif %}
